FNB AOTY 2026 Hackathon. Modules: APS, Bursaries, Resources.

Each diagram has its own Print button. Both are vector graphics, so they stay sharp at any paper size. In the print dialog choose Landscape.

Entity relationship diagram (Supabase / PostgreSQL)

PK primary key, FK foreign key. Crow's foot marks the many side, double bar marks exactly one. student_profiles.id is the Supabase Auth user id. funding_sources and scoring_weights are reference tables matched by rules in the engine, not by foreign keys. Subjects use fixed codes so Maths and Maths Literacy stay distinct. aps_bands holds each institution's mark-to-points conversion.

UML class diagram (recommendation engine, TypeScript)

Hollow diamond: the engine holds the component. Dashed arrow: depends on or produces. Dashed hollow triangle: implements. BestSixExcludingLO and BestSevenCappedLO are example strategies, one per APS method code, and each must be checked against the institution's published method. Mark, SubjectGap, Eligibility and RiskLevel types are omitted for readability. Every scoring component takes StudentProfile as its input.
