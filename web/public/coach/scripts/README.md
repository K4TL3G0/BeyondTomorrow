# Coach step voice scripts

These generic, prerecorded lines are used only when the student has enabled step audio and enters a wizard stage; the student can also replay the current step. The changing coach guidance and all personal or deadline-specific information remain text on screen.

Keep the matching audio files in `../audio/`:

- `route.txt` → `route.mp3`
- `questions.txt` → `questions.mp3`
- `documents.txt` → `documents.mp3`

Do not add student answers, household details, deadline dates, or funding status to these scripts. Deadline-specific spoken reminders are not part of this audio set.
