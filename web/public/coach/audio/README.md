# Coach step audio

The generated step clips are:

- `route.mp3`
- `questions.mp3`
- `documents.mp3`

The app plays a clip only when step audio is enabled and the student moves to a different wizard stage. Students can also replay the current step. No clip plays on initial page load or for changing answers and checklist messages. Script-to-audio mapping is documented in `../scripts/README.md`.
